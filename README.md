# GotU 💜

> **„Не си сам. Винаги има кой да ти отговори.“**

GotU е **демо (прототип)** на уеб платформа, която дава на тийнейджърите **лесен, бърз и анонимен** достъп до психолози чрез текстов чат.
Създаден е като проект по гражданско образование, замислен като пилотен проект за училища в Бургас.

> 🧪 **Важно:** това е демо версия. Всички потребители, психолози и съобщения са **измислени**. Няма истински сървър и база данни. Всичко се пази само в браузъра на устройството, на което отваряте сайта (localStorage). Отговорите на „психолозите“ са **предварително написани текстове**, не е изкуствен интелект.

## ✨ Какво има в демото

**Начална страница (за презентацията):** голямо заглавие, слоган, статистики от нашата анкета (44 младежи), „Как работи“ (01, 02, 03), „За родители“, често задавани въпроси.

**Страница „За проекта“:** обяснение на проекта и секция **„📊 Какво каза анкетата“** с всички резултати.

**Три нива на достъп:**

| Ниво | Кой | Какво може |
|---|---|---|
| **0** | Всеки, без регистрация и без родители | Чат с психолог (нищо не се запазва) или обаждане на 116 111, кратки статии по 6 теми, 6 теста от 5 въпроса |
| **1** | С училищен код | Прякор и емоджи аватар, Vibe Check, мисии, серия 🔥, значки, общност с групи по теми |
| **2** | С училищен код + съгласие на родител | Запазване на час при конкретен психолог (онлайн или на живо) |

**Играта:** Vibe Check (5 емоджи), 2–3 мисии на ден под 2 минути (винаги „Тест на деня“, плюс например анимирано дишане 4-4-4 или „Покажи с картинка“), „Мисъл на деня“, „Готово за днес! Ела утре 👋“, серия с 🔥, 2 замразявания ❄️ на седмица, значки (включително 🦁 „Смелост“ за запазен час), талисманът **Готи**, който сменя изражението си според настроението и „расте“ със серията.

**Безопасност:** ако в който и да е чат се напише кризисна дума, веднага се появява спокоен екран с **116 111** и **112** (с бутони за обаждане), а при психолога се появява **СПЕШЕН** случай. Номерата 116 111 и 112 са долу на всяка страница.

**Роли (бутон „Смени ролята (демо)“ горе вдясно):** Гост, Ученик, Психолог, Админ.

## 💻 Как да го пусна на моя компютър

Трябва ви само една програма: **Node.js**.

### Стъпка 1: Инсталирайте Node.js (само веднъж)
1. Отидете на **https://nodejs.org**
2. Свалете версията с надпис **LTS** и я инсталирайте (Next → Next → Finish).

### Стъпка 2: Свалете проекта
- В GitHub натиснете зеления бутон **Code → Download ZIP**.
- Разархивирайте ZIP файла (десен бутон → *Extract All / Извличане на всички*).

### Стъпка 3: Отворете терминал в папката
- **Windows:** отворете папката, кликнете в адресната лента горе, напишете `cmd` и натиснете Enter.
- **Mac:** десен бутон върху папката → *New Terminal at Folder*.

### Стъпка 4: Напишете тези две команди
Първата сваля нужните части (само първия път, отнема около минута):

```bash
npm install
```

Втората пуска сайта:

```bash
npm run dev
```

В терминала ще се появи адрес, например `http://localhost:5173`. Отворете го в браузъра. Готово! 🎉

> За да спрете сайта, натиснете `Ctrl + C` в терминала.

**Как да видите как изглежда на телефон:** в Chrome натиснете `F12`, после иконката с телефон 📱 горе вляво.

## 🌍 Как да го кача в интернет безплатно

### Вариант А: Netlify, без GitHub (най-лесно, 5 минути)
1. В терминала (в папката на проекта) напишете:
   ```bash
   npm run build
   ```
   Това създава папка **`dist`**: това е готовият сайт.
2. Отидете на **https://app.netlify.com/drop** (регистрирайте се безплатно, ако ви попита).
3. **Плъзнете папката `dist`** в браузъра.
4. След няколко секунди получавате линк, например `https://нещо-си.netlify.app`. Споделете го с класа! 🎉
5. (По желание) В *Site configuration → Change site name* можете да смените името, например `gotu-burgas`.

### Вариант Б: Netlify или Vercel, свързан с GitHub
Така сайтът се обновява сам всеки път, когато промените нещо в GitHub.

**Netlify:**
1. Влезте в **https://app.netlify.com** с GitHub акаунта си.
2. **Add new site → Import an existing project → GitHub** → изберете хранилището.
3. Настройките се попълват сами (Build command: `npm run build`, Publish directory: `dist`). Натиснете **Deploy**.

**Vercel:**
1. Влезте в **https://vercel.com** с GitHub акаунта си.
2. **Add New → Project** → изберете хранилището → **Import**.
3. Vercel сам разпознава „Vite“. Натиснете **Deploy**.

## 🎤 Как да го представя в час (сценарий)

⏱️ Около 7–10 минути. **Преди часа:** отворете сайта и натиснете „Смени ролята (демо)“ → **🔄 Нулирай демото**, за да е всичко като ново.

**1. Проблемът (1 мин)** – начална страница, секция „Проблемът“
> „В България има безплатна линия с психолози: 116 111. Но нашата анкета с 44 младежи показа, че 57% дори не знаят за нея, а 73% никога не са ходили при училищния психолог. В същото време 45% понякога или често имат нужда да поговорят с някого, но нямат с кого.“

> „Очаквахме, че повечето ще искат да пишат, а не да звънят. Оказа се почти наравно: 45% срещу 43%. Затова в GotU можеш и двете.“ (Честността печели точки! 😉)

**2. Решението (1 мин)** – „Как работи“, трите карти 01, 02, 03
> „GotU е като Kooth във Великобритания: анонимен чат с психолози, безопасна общност и малко игра.“

**3. Ниво 0: Гост (1–2 мин)**
- Натиснете **„Пиши анонимно сега“** → **Започни чат** → напишете нещо. Покажете, че отговорите са отбелязани като **демо**.
- Натиснете **„Затвори и изтрий“**: нищо не остава.
- Покажете набързо **Статии** и един **тест**.

**4. Безопасност (1 мин)** – най-важната част!
- В чата напишете например: `не искам да живея`.
- Появява се спокоен екран със слогана, **116 111** и **112**.
> „Съобщението не чака одобрение. Психологът веднага получава спешен сигнал.“

**5. Ниво 1: Ученик (2 мин)** – „Смени ролята“ → **Ученик**
- Покажете **Готи**, серията 🔥 12 и замразяванията ❄️.
- Натиснете 😔 във **Vibe Check**: Готи става тъжен и се появява „Изглежда ти е тежко напоследък…“, защото и предишните два дни са били ниски.
- Направете мисията **Дишане 4-4-4**.
- В **Общност** напишете съобщение: виждате „⏳ Чака одобрение“.

**6. Ниво 2: Час при психолог (1 мин)** – меню **Час**
- „Симулирай Да“ за съгласие на родител → изберете психолог → час → **Запази** → значка **🦁 Смелост**!
> „Искаме търсенето на помощ да е нещо готино, не нещо срамно.“

**7. Психолог и Админ (1–2 мин)**
- **Психолог:** спешният случай от стъпка 4 е най-горе. Покажете часовете и личните чатове.
- **Админ:** одобрете съобщението от стъпка 5 → **Статистика** с графиката на настроението.

**8. Край**
> „Не си сам. Винаги има кой да ти отговори.“ 💜

### Още демо трикове
- **⏩ Превърти 1 ден напред** (в менюто „Смени ролята“ или долу на началния екран на ученика) „прескача“ един ден: нови мисии, серията расте. Ако го натиснете два пъти без Vibe Check, ще видите как работи **замразяването ❄️**: серията не се губи и излиза „Няма проблем, продължаваме заедно.“
- **Регистрация:** като Гост натиснете „Регистрирай се с код“ и въведете **GOTU-006** (свободен). Опитайте и **GOTU-012**: вече е използван, защото „един код = един акаунт“. Изберете възраст **13**, за да видите стъпката „Съгласие от родител“.
- **Правило „2 неявявания“:** като Психолог натиснете два пъти „🚫 Не се яви“ на часовете на демо ученика. Когато ученикът запази нов час, той ще чака одобрение от психолога.

## ✏️ Как да сменя текстове и числа

Можете да редактирате файловете с безплатната програма **Visual Studio Code** (https://code.visualstudio.com) или директно в GitHub (иконка с моливче ✏️).

| Какво искам да сменя | Файл |
|---|---|
| Статистиките на началната страница | `src/pages/Landing.jsx` (най-горе, `STATS`) |
| Резултатите от анкетата (страница „За проекта“) | `src/data/survey.js` |
| Мисъл на деня | `src/data/quotes.js` |
| Въпросите (FAQ) и текста за родители | `src/pages/Landing.jsx` (`FAQ`, `PARENTS`) |
| Страница „За проекта“ | `src/pages/About.jsx` |
| Статии и тестове | `src/data/articles.js` |
| Мисии | `src/data/missions.js` |
| Значки | `src/data/badges.js` |
| Психолози и демо отговорите в чата | `src/data/psychologists.js` |
| Кризисни думи | `src/data/crisis.js` |
| Цветове | `tailwind.config.js` (`grape` = лилаво, `coral` = корал, `mint` = мента) |

> Сменяйте само текста между кавичките `'...'`, без да триете самите кавички и запетаите.

## 🔧 Как е направено (за любопитните)

- **React:** библиотека за изграждане на екраните.
- **Vite:** пуска сайта по време на работа и го „пакетира“ за интернет.
- **Tailwind CSS:** дизайнът (цветове, заоблени карти, анимации).
- **localStorage:** малко „чекмедже“ в браузъра, където демото пази данните си. Няма сървър.
- **Готи** е нарисуван с код (SVG) в `src/components/Mascot.jsx`.

```
src/
  pages/        ← всеки екран (начало, чат, общност, табла…)
  components/   ← общи части (горна лента, долу, Готи, кризисен екран)
  data/         ← текстове и демо данни
  store.jsx     ← „мозъкът“: правилата за серия, часове, роли
```

### ⚠️ Какво е нужно за истински продукт
Това демо показва **идеята**. За истинска платформа ще трябват: истински психолози, сървър със защитени данни (по GDPR), проверка на кризисния протокол и списъка с ключови думи **от специалисти**, реално съгласие от родител и договор с училищата.
